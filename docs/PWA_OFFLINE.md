# PWA & Offline — 2026-10-30

## What ships

- **Real PNG icons**: 192, 512, a maskable 512, a 32 px favicon and a 180 px Apple touch icon in `icons/`.
- **Manifest**: standalone display, `scope: /`, `id: /`, portrait-or-landscape (`orientation: any`), cream splash background, green theme.
- **Service worker**: generated by `scripts/cache-bust.js` into `sw.js`.
- **Registration**: `pwa.js`, loaded as a module before the game boot.

## Cache strategy

The worker precaches the entire offline shell on install:

- `/` and `/index.html`
- every hashed script and stylesheet referenced by `index.html`
- `manifest.json?v=<hash>`
- all five PNG icons
- all 28 animal cues (~1.35 MB)

Total precache: **46 URLs, about 1.9 MB** (the shell plus all 28 animal cues and the icons).

- **Navigation**: network-first, falling back to the cached `index.html` when offline.
- **Assets and audio**: cache-first, then network, then a 503. New audio is written to the runtime cache when first fetched.
- **Updates**: the cache name is a SHA-256 of the precache URL list plus the content hash of every precached file (shell, scripts, manifest, icons and cues). When any of them changes, the version changes, the new worker installs, `skipWaiting` + `clients.claim` take over, and the activate handler deletes old `wild-animals-*` caches.

## Why the audio diet mattered here

Precaching 631 MB would be absurd. The diet brought the full cue set to 1.34 MB, so a complete offline install fits comfortably in a classroom tablet's storage and on a slow connection.

## Verification

```bash
npm run build            # writes sw.js from the final hashes
npm run test:unit        # PWA asset guard + audio guard + contrast tokens
npx playwright test test/e2e/pwa.spec.js --project=chromium
```

The offline spec loads the app, waits for the worker, reloads to become controlled, switches the browser context offline, reloads again, asserts the title and four answer options, and decodes the Parrot cue from the cache.

## Icon provenance

The master icon was generated with a flat-vector children's-app prompt: friendly cartoon lion face, golden mane, deep green circular background, no text, generous maskable padding. It was resized with Lanczos and quantised to 128 colours. The master is not committed; the derived PNGs are. To regenerate, replace `icons/icon-512.png` and re-run the resize/quantise step, then `npm run build` so the service-worker cache version changes.

## Operational notes

- `sw.js` must be served with `Cache-Control: public, max-age=0, must-revalidate`; `vercel.json` and `_headers` do this.
- A service worker only runs in a secure context (HTTPS or `localhost`).
- Test a real update by changing a script, running `npm run build`, reloading twice, and confirming the old cache name disappears from DevTools → Application → Cache Storage.
